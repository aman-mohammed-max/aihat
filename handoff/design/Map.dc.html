What every tap opens

Screen names are links: press Play on any screen and they work the same way. Back and ✕ return to where you came from; sheets close with Done or a tap outside.

Primary action Destructive
Chat
  • ☰ → Side menu
  • Model name → Model picker
  • ✎ → New chat · ⋯ → Chat options
  • Prompt pill → System prompt picker
  • Skill / MCP chip in a reply → Skill / Server
  • Long-press or ⋯ on a message → Message actions
  • Endpoint fails → Error card with Retry, Switch model, Endpoint
Message box (every chat)
  • + → Add menu: camera, photos, files, Drive, iCloud, web, image
  • Sliders → Tools for this chat
  • Search / Image chip → tap to switch that mode off
  • Mic → Voice input & translation
  • Send (accent) → sends; files upload first and show progress in the box
Side menu
  • Search chats → Search results
  • System prompts, Skills, MCP servers, Connectors
  • Pinned app → Full-screen mini app
  • Chat → opens it · long-press → Chat options
  • Profile → Settings
Chat options ⋯
  • Rename · Pin to top (in place)
  • System prompt → picker
  • Model settings → temperature, length, reasoning
  • Tools → Tools for this chat
  • Export → Markdown, PDF, Google Drive
  • Delete → Confirm dialog
Files, web & images
  • Files / Drive → File chat: citations show page or line
  • Search the web → Web search chat → Sources → Search settings
  • Photos / Create image → Image chat → Viewer: Save, Drive, Vary, Share
  • iCloud (not linked) → Connect
Models & providers
  • Pick a model → back to chat with it
  • Offline · why? → Error details
  • Manage providers → Providers → Detail
  • + / Add endpoint → New endpoint: presets, URL, key, test, pick models
  • First run → Welcome → Add endpoint or on-device model
Prompts, skills & MCP
  • Prompt row or + → Editor with variables, model, tools
  • Skill row → Skill detail · + → Add skill (Git, .zip, write)
  • Server row → Server detail: per-tool Auto / Ask / Off
  • + → Add MCP server (URL or JSON) · Connectors → Sign in
Settings
  • Appearance · Chat defaults
  • Providers · Skills · MCP · Generative UI
  • Voice & speech · Images · Web search · Files
  • Sync & backup · Privacy & keys · About
Generative UI Replies can be cards and forms that stream in. Buttons that write data open Allow this action? first. “View spec” → Spec inspector. Settings → Generative UI → Components & actions. Apps can open full screen and be pinned.

Why does my QEMU wrapper crate leak file descriptors when the VM restarts?
code-review github.search_code3 files

The fds come from spawn_vm(). Each restart opens a new QMP socket, but the old UnixStream moves into a detached thread that never exits.

impl Drop for VmHandle {
    fn drop(&mut self) {
        let _ = self.qmp.shutdown(Both);
        self.monitor.join().ok();
    }
}
